# LLM: воспроизводимое использование ИИ

- `prompts/` — роли ИИ: `tutor`, `socratic`, `examiner`, `reviewer`, `researcher`. Менять через правку файла, а не в каждом чате.
- `evaluations/` — рубрика `response-rubric.md`: по ней проверяется, полезен ли ответ ИИ.
- `outputs/` — сохранённые полезные ответы ИИ. Большие или временные ответы сюда не складывать.

Запросы фиксируются в `x_meta/log/queries.md` по шаблону `templates/query.md`: цель, промпт, разрешённый контекст, результат проверки.

Правило: ИИ получает только минимальный разрешённый контекст, то есть конкретные файлы или фрагменты, а не всю папку. Просим цитировать только этот контекст.

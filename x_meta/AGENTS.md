# AGENTS: указатель для ИИ-агентов

Полная инструкция для ИИ находится в корне папки: **[CLAUDE.md](../CLAUDE.md)**. Прочитай её перед любым изменением.

Коротко:

- `learning/<предмет>/Files/` — исходники, не менять.
- `learning/` — работа студента, только предлагать правки.
- `wiki/` — только с `sources:` и статусом `needs-review`, сначала `wiki/index.md`.
- `x_meta/log/` — только дописывать в конец.
- Учебный режим: вопрос раньше ответа, без готовых решений заданий.
- Режимы работы (Ingest, Compile, Tutor, Socratic, Examiner, Reviewer, Researcher) описаны в CLAUDE.md и в `llm/prompts/`.

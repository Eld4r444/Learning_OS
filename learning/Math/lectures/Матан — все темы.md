## Лекция — Матан — 03.09.26
### Алгебраическая форма записи комплексного числа
*(в расписании 03.09 по матану стоит только практика — видимо, теория была в начале пары)*

$x^2 + 1 = 0$
$x^2 = -1$ — нет решений в $\mathbb{R}$
$i = \sqrt{-1}$ — **мнимая единица**, $i^2 = -1$

Ур-е $x^2 + 1 = 0$ имеет решение (2 корня): $x_1 = i,\ x_2 = -i$, $i \notin \mathbb{R}$

$x^2 + x + 1 = 0$
$D = 1 - 4 = -3 < 0$ — нет действительных корней
$\sqrt{D} = \sqrt{-3} = \sqrt{-1}\cdot\sqrt{3} = i\sqrt{3}$
$x_1 = \frac{-1 + i\sqrt3}{2}$
$x_2 = \frac{-1 - i\sqrt3}{2}$

**Определение:** комплексным числом называется число $z = x + y\cdot i$, где $x, y \in \mathbb{R}$
$x$ — называется **действительной частью** числа $z$: $\operatorname{Re} z = x$
$y$ — наз. **мнимой частью** числа $z$: $\operatorname{Im} z = y$

**Пример:** $z_1 = 5 - 4i$, $\operatorname{Re} z_1 = 5$, $\operatorname{Im} z_1 = -4$
$\qquad\quad z_2 = -2 - 3i$, $\operatorname{Re} z_2 = -2$, $\operatorname{Im} z_2 = -3$

$\mathbb{C}$ — мн-во комплексных чисел
Если $y = 0$, то $z \in \mathbb{R}$, $\mathbb{R} \subset \mathbb{C}$

#### Операции над комплексными числами

**1) Операция сложения и вычитания**
$z_1 = x_1 + y_1 i$, $z_2 = x_2 + y_2 i$
$z_1 + z_2 = x_1 + y_1 i + x_2 + y_2 i = (x_1 + x_2) + (y_1 + y_2)i$
$z_1 - z_2 = x_1 + y_1 i - x_2 - y_2 i = (x_1 - x_2) + (y_1 - y_2)i$

**Пример:**
$z_1 = 2 + 3i$, $z_2 = -5 + 4i$
$z_1 + z_2 = -3 + 7i$
$z_1 - z_2 = 7 - i$

**2) Операция умножения**
$z_1\cdot z_2 = (2 + 3i)(-5 + 4i) = -10 + 8i - 15i + 12i^2 = -10 + 8i - 15i - 12 = -22 - 7i$

**3) Операция сопряжения**
$z = x + yi$ → $\bar z = x - yi$ — сопряж. к $z$ число
$z = -2 - 3i$ → $\bar z = -2 + 3i$

$z\cdot\bar z = (x + yi)(x - yi) = x^2 - (yi)^2 = x^2 + y^2 \in \mathbb{R}$

**4) Операция деления**, $z_2 \ne 0$
$$\frac{z_1}{z_2} = \frac{z_1\cdot\bar z_2}{z_2\cdot\bar z_2} = \frac{(\ \ )\cdot(\ \ )}{(\ \ )\cdot(\ \ )}$$

**Пример:**
$$\frac{-2 + 3i}{1 + 2i} = \frac{(-2 + 3i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \frac{-2 + 4i + 3i - 6i^2}{1 - 2i + 2i - 4i^2} = \frac{-2 + 7i + 6}{1 + 4} = \frac{4 + 7i}{5} = \frac45 + \frac75 i$$

# 3. 2026-09-10 Лекция — Теория пределов
*Источник: [[2026-09-10 Лекция — Теория пределов]]*

## Лекция — Матан — 10.09.26
### Теория пределов

#### Основные обозначения
$a \Rightarrow b$ — «из предложения $a$ следует предложение $b$»
$a \Leftrightarrow b$ — «предл. $a$ и $b$ равносильны: из $a$ следует $b$ и из $b$ следует $a$»
$\forall$ — «для любого», «для всякого»
$\exists$ — «существует», «найдётся»
$:$ — «такое что»

$A \cup B\ (A + B)$ — объединение
$A \cap B$ (или $A\cdot B$) — пересечение
$A \setminus B\ (A - B)$ — разность мн-в

$x \in X$, $\quad x \notin X$, $\quad \varnothing$, $\quad A = \{a, b, c, \ldots\}$
$n! = 1\cdot2\cdot3\cdot\ldots\cdot n$, $0! = 1$
$\sum_{k=1}^{n} a_k = a_1 + a_2 + \ldots + a_n$

Последовательность $a_n$, $n = 1, 2, 3, \ldots$ будет обознач. $\{a_n\}$
В круглых скобках заключ. утверждение, вытекающее из предыдущих действий.

$\mathbb{R}$ — мн-во действ. чисел
$\mathbb{N} = \{1, 2, 3, \ldots\}$
$\mathbb{Z} = \{0, \pm1, \pm2, \ldots\}$

#### Определение 2.1 (Коши)
Число $a$ называется **пределом последовательности** $\{x_n\}$ (обознач. $\lim\limits_{n\to\infty} x_n = a$), если для каждого $\varepsilon > 0$ сущ-ет $N$, зависящий от $\varepsilon$ такой, что для всех номеров $n > N$ будет выполняться нер-во $|x_n - a| < \varepsilon$. Или в краткой записи:

$$\lim_{n\to\infty} x_n = a \Leftrightarrow \forall\varepsilon > 0\ \exists N = N(\varepsilon):\ \forall n > N\ (|x_n - a| < \varepsilon)$$

#### 2.2
Интервал $U(a, \varepsilon) = (a - \varepsilon, a + \varepsilon)$ называется **ε-окрестностью** точки $a$ (или просто её окрестностью) и обозначается тогда $U(a)$. Мн-во $U(a, \varepsilon)\setminus\{a\}$ называется **проколотой ε-окрест.** (или прокол. окрест.) точки $a$ и обозначается $\mathring U(a, \varepsilon)$ (или $\mathring U(a)$).

*[рисунки: $U(a,\varepsilon)$ — отрезок на прямой $a-\varepsilon,\ a,\ a+\varepsilon$; $\mathring U(a,\varepsilon)$ — то же, точка $a$ выколота]*

#### 2.3 (равносильно 2.1)
$$\lim_{n\to\infty} x_n = a \Leftrightarrow \forall\varepsilon > 0\ \exists N = N(\varepsilon):\ \forall n > N\ (x_n \in U(a, \varepsilon))$$

$|x_n - a| < \varepsilon$
$-\varepsilon < x_n - a < \varepsilon$
$a - \varepsilon < x_n < a + \varepsilon$
$x_n \in U(a, \varepsilon)$

*[рисунок: на прямой $x_1, x_2, x_3, x_4$ … затем $(a-\varepsilon\ \ x_5\ \ a\ \ x_6\ \ a+\varepsilon)$]*

**Пример:** Док-ть, что $\lim\limits_{n\to\infty}\frac{(-1)^{n+1}}{n} = 0$, $a = 0$

**Док-во:** Проверим, что $\forall\varepsilon > 0\ \exists N = N(\varepsilon):\ \forall n > N$
$\left(\left|\frac{(-1)^{n+1}}{n} - 0\right| < \varepsilon\right) \Leftrightarrow \frac1n < \varepsilon \Leftrightarrow n > \frac1\varepsilon$. Значит, в кач-ве $N$ можно взять любой номер, такой, что $N \ge \frac1\varepsilon$: если $n > N$, а $N \ge \frac1\varepsilon$, то $n > \frac1\varepsilon$ (также видно, что чем меньше $\varepsilon$, тем больше $N$)

| ε | 0,5 | 0,01 | 0,3 |
|---|---|---|---|
| N | 2 | 100 | 3,(3) |

$U_{0,3}(0)$: 4, 5, 6, …

#### 2.4
$$\lim_{n\to\infty} x_n = +\infty \Leftrightarrow \forall M > 0\ \exists N = N(M) > 0:\ \forall n > N\ (x_n > M)$$
(члены последовательности сколь угодно велики, т.е. больше любого наперёд заданного числа $M$, если номера $n$ этих членов дост. велики, т.е. превосходят номера $n$, большие некоторого $N$)

$x_n = \log_{10} n$, $n = 1, 2, 3, \ldots$
$x_1 = 0$, $x_{10} = 1$, $x_{100} = 2$, $x_{1000} = 3$, $x_{10000} = 4$
$M = 100$, $x_{10^{101}} = 101$
$\lim\limits_{n\to\infty}\log_{10} n = +\infty$

$$\lim_{n\to\infty} x_n = -\infty \Leftrightarrow \forall M < 0\ \exists N = N(M) > 0:\ \forall n > N\ (x_n < M)$$
$$\lim_{n\to\infty} x_n = \infty \Leftrightarrow \forall M > 0\ \exists N = N(M) > 0:\ \forall n > N\ (|x_n| > M)$$

Все послед-ти трёх таких типов называются **бесконечно большими**.

#### Определение предела ф-ции по Коши 2.5
Пусть ф-ция $y = f(x)$ определена в некоторой окрестности $\mathring U(a)$. Тогда
$$\lim_{x\to a} f(x) = b \Leftrightarrow \forall\varepsilon > 0\ \exists\delta = \delta(\varepsilon) > 0:\ \forall x \in \mathring U(a, \delta)\ (f(x) \in U(b, \varepsilon))$$
Или
$$\forall\varepsilon > 0\ \exists\delta = \delta(\varepsilon):\ \forall x,\ 0 < |x - a| < \delta\ (|f(x) - b| < \varepsilon)$$
($x$ приближ. к $a$, но не равен $a$)

Согласно опред-ю при $a - \delta < x < a + \delta$ гр-к ф-ции лежит в полосе $b - \varepsilon < y < b + \varepsilon$. При опред. $\delta$ отрезки $[c, a]$ и $[a, d]$, как правило, не равны друг другу. Чтобы не выйти за пределы полосы $(b - \varepsilon, b + \varepsilon)$, надо исходить из ближ-го к $a$ края отрезков $c$ или $d$. При уменьшении $\varepsilon$ соответственно уменьшается и $\delta$.

*[график: возрастающая кривая; по оси y — $b-\varepsilon,\ b,\ b+\varepsilon$; по оси x — $c,\ a-\delta,\ a,\ d = a+\delta$]*

**Пример:** Док-ть, что $\lim\limits_{x\to0} 10^{|x|} = 1$.

**Док-во.** Проверим, что $\forall\varepsilon > 0\ \exists\delta = \delta(\varepsilon):\ \forall x,\ 0 < |x| < \delta\ (|10^{|x|} - 1| < \varepsilon)$. Так как $10^{|x|} - 1 \ge 0$, то имеем, что
$$10^{|x|} - 1 < \varepsilon \Leftrightarrow 10^{|x|} < 1 + \varepsilon \Leftrightarrow |x| < \lg(1 + \varepsilon)$$
Отсюда ясно, что в качестве $\delta$ можно взять любое число, такое, что $\delta \le \lg(1 + \varepsilon)$. Тогда, если $|x| < \delta$, а $\delta \le \lg(1 + \varepsilon)$, то $|x| < \lg(1 + \varepsilon)$.

$a = 0$, $b = 1$, $f(x) = 10^{|x|}$
$0 < |x - a| < \delta$
$|f(x) - b| < \varepsilon$
$|10^{|x|} - 1| < \varepsilon$

$f_n\cdot x^n + f_{n-1}\cdot x^{n-1} + \ldots + f_1 x + f_0 = 0$
$n = 1, 2, 3, 4, 5, \ldots$
Ур-е имеет $n$ комплексных корней с учётом их кратности.

### 3. Пределы функций — определение (было на лекции)
Число $A$ называется **пределом функции** $y=f(x)$ при $x\to x_0$, если для всех значений $x$, достаточно мало отличающихся от $x_0$, соответствующие значения $f(x)$ как угодно мало отличаются от $A$, т.е.
$$\forall\varepsilon>0\ \ \exists\delta>0:\ \ \forall x\ne x_0,\ |x-x_0|<\delta\ \Rightarrow\ |f(x)-A|<\varepsilon.$$
Это **определение Коши** ($\varepsilon$–$\delta$).

**Пример 3.1.1.** Доказать, что $f(x)=3x-2$ в точке $x=1$ имеет предел, равный 1: $\lim\limits_{x\to1}(3x-2)=1$.

Возьмём $\delta\le\dfrac\varepsilon3$ — тогда из $|x-1|<\delta$ следует $|f(x)-A|<\varepsilon$, ч.т.д. *(такого на дом не будет)*

### Пределы показательной и логарифмической функций на бесконечности
**Показательная функция $a^x$ ($a>0$):**
$$a^{+\infty}=\begin{cases}+\infty,&a>1\\0,&0<a<1\\\text{не опр.},&a=1\end{cases}\qquad\boxed{a^{-\infty}=\frac1{a^{+\infty}}}\qquad a^{-\infty}=\begin{cases}0,&a>1\\+\infty,&0<a<1\\\text{не опр.},&a=1\end{cases}$$

### Неопределённость $\frac00$
Почему не определена: «ноль» — это очень малое число, но порядок малости числителя и знаменателя может быть разный:
$$\frac{10^{-2}}{10^{-10}}=10^{8}\to\infty,\qquad\frac{10^{-10}}{10^{-2}}=10^{-8}\to0,\qquad\frac{10^{-10}}{10^{-10}}=1.$$
**Способ раскрытия:** разложить числитель и знаменатель на множители и **сократить общий множитель, дающий ноль** (если общего множителя нет — ошибка в корнях).

### Единственность предела последовательности и функции

> **2.1 Теорема:** Последовательность (функция) не может иметь более одного предела.

1. Пусть $\lim\limits_{x\to\infty}x=a_1$ и $\lim\limits_{x\to\infty}x=a_2$, $a_1\ne a_2$. Выберем окрестности такие, что $U_1\cap U_2=\varnothing$. Согласно определению 2.3: $\exists N_1:\forall n>N_1\ (x_n\in U(a_1))$ и $\exists N_2:\forall n>N_2\ (x_n\in U(a_2))$ — против.

#### Ограниченная последовательность
$\{x_n\}$ ограничена $\Leftrightarrow\exists M>0:\forall n\in\mathbb N\ (|x_n|\le M)$.
Посл. ограничена сверху или снизу.
Пример: $x_n=\dfrac1n$, $n=1,2\dots$: $x_2=\dfrac12$, $x_3=\dfrac13$, $x_4=\dfrac14$; $x_n\le1$, $\forall n\in\mathbb N$.

> **2.2 Теорема:** Если последовательность (функция) имеет конечный предел, то она ограничена (при $x\to a$).

### Бесконечно малые последовательности и функции
**Опр.** Последовательность $\{x_n\}$ называется **бесконечно малой** (б.м.), если $\lim\limits_{n\to\infty}x_n=0$. Функция $y=f(x)$ называется бесконечно малой при $x\to a$ (б.м., $x\to a$), если $\lim\limits_{x\to a}f(x)=0$.
$$\{x_n\}\text{ — б.м.}\Leftrightarrow\forall\varepsilon>0\ \exists N=N(\varepsilon):\forall n>N\ (|x_n|<\varepsilon)$$
$$y=f(x)\text{ — б.м., }x\to a\Leftrightarrow\forall\varepsilon>0\ \exists\delta=\delta(\varepsilon):\forall x\in\mathring U(a,\delta)\ (|f(x)|<\varepsilon)$$
Пример: $f(x)=\dfrac1{x^2}$: $x\to\infty$ — $f(x)\to0$; $x\to0$ — не явл. беск. мал. $f(x)=\sin x$: $\lim\limits_{x\to0}f(x)=\sin0=0$.

> **2.3 Теорема:** Сумма 2-х беск. м. послед. (функций при $x\to a$) есть последов. (функция при $x\to a$) бесконечно малая.

> **2.4 Теорема:** Произведение б.м. посл. (функции при $x\to a$) на ограниченную посл. (функцию при $x\to a$) есть посл. (функция при $x\to a$) б.м.

> **2.5 Теорема:** Частное от деления б.м. посл. (функции при $x\to a$) на последов. (функцию), имеющую (при $x\to a$) конечный или отличный от 0 предел, есть посл. (функция при $x\to a$) бесконечно малая.

> **2.6 Теорема:** Для того чтобы предел посл. (функции при $x\to a$) был равен некоторому числу $b$, необходимо и достаточно, чтобы эту посл. (функцию) можно было представить в виде суммы числа $b$ и б.м. посл. (функции при $x\to a$).
$$\lim_{n\to\infty}x_n=b\Leftrightarrow x_n=b+a_n,\ \{a_n\}\text{ — посл. б.м.}$$
$$\lim_{x\to a}f(x)=b\Leftrightarrow f(x)=b+a(x),\ a(x)\text{ — функ. б.м. (при }x\to a)$$
Необходимость: $\lim x_n=b\Leftrightarrow\forall\varepsilon>0\ \exists N=N(\varepsilon):\forall n>N\ (|x_n-b|<\varepsilon)$.

> **2.7 Теорема:** Предел суммы двух посл. (функций) равен сумме пределов этих посл. (функций), если эти пределы существуют.

Пусть $\lim x_n=a$, $\lim y_n=b$ (теор. необх. 2.6): $x_n=a+a_n$, $y_n=b+b_n$. Сложим: $x_n+y_n=(a+b)+(a_n+b_n)$ ($a+b$ — число, $a_n+b_n$ — б.м. по теор. 2.3) $\Rightarrow$ по теор. 2.6 $\lim\limits_{n\to\infty}(x_n+y_n)=a+b$.

> **2.8 Теорема:** Предел произв. двух посл. (функ.) равен произв. пределов этих посл. (функ.), если эти пределы существуют.

1. **Следствие:** Постоянный множитель можно выносить за знак предела.
2. **Следствие:** Предел разности двух последоват. (функ.) равен разности пределов этих посл. (функ.), если эти пределы сущ.

> **2.9 Теорема:** Предел отношения двух посл. (функ.) равен отношению пределов этих последов. (функ.), если эти пределы существ. и предел знаменателя отличен от 0.

**Замечания:**
1. Теоремы о пределах функций справедливы и при $a\to\infty$.
2. В теоремах о пределах посл. и функ. допускаются и беск. пред., если это имеет смысл:
$(+\infty)+(+\infty)=+\infty$; $(-\infty)+(-\infty)=-\infty$; $(+\infty)-(-\infty)=+\infty$; $\infty\cdot\infty=\infty$; $b\cdot\infty=\infty\ (b\ne0)$; $\dfrac b\infty=0\ (b\ne\infty)$; $\dfrac b0=\infty\ (b\ne0)$.
3. $(+\infty)-(+\infty)$; $0\cdot\infty$; $\dfrac00$; $\dfrac\infty\infty$ и т.д. — это так называемые **неопределённости** (т.е. случаи, где основн. теоремы о пределах сразу не применимы)

**Некоторые теоремы о пределах последовательностей и функций**

**2.9 Опр.:** Последоват. $\{x_n\}$ называется **неубывающей** (**невозрастающей**), если для всех $n\in\mathbb N$ выполняется следующее условие: $x_{n+1}\ge x_n$ ($x_{n+1}\le x_n$).
Последов. $\{x_n\}$ называется **монотонной**, если она является либо неубывающей, либо невозрастающей.

### Производная параметрической функции
$$\begin{cases}x=x(t)\\y=y(t)\end{cases}$$
1. $\begin{cases}x=\cos t\\y=\sin t\end{cases}$ $x^2+y^2=1$; $\begin{cases}x=a\cos t\\y=b\sin t\end{cases}$ $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$; $\begin{cases}x=t-\sin t\\y=1-\cos t\end{cases}$ — «Циклоида»
*[рисунок: окружность, катящаяся по прямой]*
$$\boxed{y'_x=y'_t\cdot t'_x=\frac{y'_t}{x'_t}}\qquad\boxed{y''_{x^2}=(y'_x)'_x=(y'_x)'_t\cdot t'_x=\frac{(y'_x)'_t}{x'_t}}\qquad\boxed{y'''_{x^3}=\frac{(y''_{x^2})'_t}{x'_t}}$$
Пример: $y'_x=\dfrac{\cos t}{-\sin t}=-\operatorname{ctg}t$;
$$y''_{x^2}=\frac{\frac1{\sin^2t}}{-\sin t}=-\frac1{\sin^3t}$$
> ✏️ *исправлено: в тетради $y''=\frac1{-\sin^2t\,(-\sin t)}=\frac1{\sin^3t}$; но $(-\operatorname{ctg}t)'=+\frac1{\sin^2t}$, поэтому ответ $-\frac1{\sin^3t}$.*

### Дифференцируемые функции. Дифференциал функции
$y=f(x)$, $\Delta y=f(x+\Delta x)-f(x)$. Пусть это приращение можно представить в виде:
$$\Delta y=A\Delta x+\alpha\Delta x\quad(1),\qquad A=A(x),\ \alpha=\alpha(x,\Delta x)\text{ — б.м., }\Delta x\to0$$
- Тогда наша ф-ция наз. **дифференцируемой** в точке $x$, а $A\Delta x$ — **дифференциалом** функции.
- Как говорят, дифференциал ф-ции — это главная линейная часть приращения этой функции.

**Пример:** $y=x^2$: $\Delta y=(x+\Delta x)^2-x^2=2x\Delta x+(\Delta x)^2$, $A=2x$, $\alpha=\Delta x\to0$; $dy=2x\,dx$.

> **Теорема:** $y=f(x)$ дифференцируема в точке $x$ — это всё равно что существует $f'(x)$ и $A=f'(x)$.

**Д-во:**
1. $f(x)$ — дифф., тогда $\Delta y=A\Delta x+\alpha\Delta x\Rightarrow\dfrac{\Delta y}{\Delta x}=A+\alpha\Rightarrow\exists f'(x)=\lim\limits_{\Delta x\to0}\dfrac{\Delta y}{\Delta x}=\lim\limits_{\Delta x\to0}(A+\alpha)=A+0=A$
2. $\exists f'(x)=\lim\limits_{\Delta x\to0}\dfrac{\Delta y}{\Delta x}\Rightarrow\dfrac{\Delta y}{\Delta x}=f'(x_0)+\alpha$, $\alpha$ — б.м., когда $\Delta x\to0$ $\Rightarrow\Delta y=f'(x_0)\Delta x+\alpha\Delta x$. Значит $y=f(x)$ — дифф. и $A=f'(x)$.

$$\boxed{dy=(y')\Delta x,\quad\Delta x=dx\Rightarrow y'dx}$$
$y=x^2$, $dy=2x\,dx$. Дифф. функции — это произв. на $dx$.

#### Применение дифф. для приближ. вычислений
$$\Delta y=dy+\alpha\Delta x;\quad f(x+\Delta x)-f(x)=f'(x)\Delta x+\alpha\Delta x;\quad\boxed{f(x+\Delta x)\approx f(x)+f'(x)\Delta x}$$
$\sqrt[5]{33}$: $f(x)=\sqrt[5]x$, $x=32$, $\Delta x=1$, $f'(x)=\dfrac15x^{-\frac45}$
$$\sqrt[5]{32+1}\approx\underbrace{\sqrt[5]{32}}_2+\underbrace{\frac1{5\sqrt[5]{32^4}}}_{\frac1{80}};\qquad\sqrt[5]{32+1}\approx2+\frac1{80}$$
*(в тетради показатель записан как $-\frac75$ — по смыслу $-\frac45$, результат $\frac1{80}$ верный)*

$$(u\pm v)^{(n)}=u^{(n)}\pm v^{(n)},\qquad(cu)^{(n)}=cu^{(n)}$$
$$(uv)^{(n)}=u^{(n)}v+nu^{(n-1)}v'+\frac{n(n-1)}{2!}u^{(n-2)}v''+\frac{n(n-1)(n-2)}{3!}\dots$$
$(uv)'=u'v+uv'$; $(uv)''=u''v+2u'v'+uv''$; $(uv)'''=u'''v+3u''v'+3u'v''+uv'''$

### Дифференциалы высших порядков
$y=f(x)$; $dy=f'(x)dx$; $d^2y=d(dy)=d(f'(x)dx)=f''(x)dx^2$ $\big((dx)^2\big)$; $d^3y=d(d^2y)=f'''(x)dx^3$; …

#### Инвариантность формы дифф. относительно выбора переменной
$y=f(x)\Rightarrow dy=y'_xdx$
$y=f(t)$, $t=\varphi(x)\Rightarrow y=f(\varphi(x))$; $dy=y'dx=y'_t\cdot\underbrace{t'_x\cdot dx}_{dt}=y'_tdt$

Таким образом формула $dy=y'dx$ не только для незав. переменной $x$, но и в случае когда $x$ является функцией какой-нибудь переменной $t$. Это св-во наз. **инв. формы дифф. относ. выбора переменной**.
*(в тетради «$y=y'dx$» — пропущено $d$)*

$$d^2y=y''(dx)^2$$

### Некоторые теоремы о дифф. функциях
**1. Теорема Ферма.**
Пусть ф-ция $y=f(x)$ опред. на $[A;B]$ и во внут. т. отрезка $c$ принимает своё наиб. или наим. значение, тогда, если сущ. конеч. $f'(c)\Rightarrow f'(c)=0$.
*[рисунки: отрезок $[A;B]$ с точкой $c$; три графика — максимум внутри отрезка; возрастающая функция, наибольшее значение на конце $B$; острый пик в $c$, где производной нет]*

**Д-во:** $f'(c)=\lim\limits_{\Delta x\to0}\dfrac{f(c+\Delta x)-f(c)}{\Delta x}$, пусть в т. $c$ — наиб. знач.
$\Rightarrow$ числитель дроби меньше или равен 0 $\Rightarrow$
- $\Delta x>0$, дробь $\le0\Rightarrow$ предел дроби $f'(c)\le0$
- $\Delta x<0$, дробь $\ge0\Rightarrow$ предел дроби $f'(c)\ge0$

$\Rightarrow$ Предел дроби $=0$.

**2. Теорема Ролля.**
Пусть ф-ция $y=f(x)$, опред. и непр. на $[A;B]$, имеет произв. во всех внут. т. этого отрезка, пусть $f(a)=f(b)$, тогда сущ. хотя бы 1 $c\in[A;B]$, такая что $f'(c)=0$.
*[рисунок: функция на $[a,b]$ с равными значениями на концах и горизонтальной касательной в $c$]*

**Д-во:** Т.к. функция непр. на отрезке, то в некоторых точках отрезка она принимает своё наиб. и наим. значение $(M,m)$:
1) $M=m$, $f(x)=\text{const}\Rightarrow f'(x)=c'=0$
2) $M\ne m$, тогда хотя бы одно из этих значений принимается внутри отрезка, тогда по **Теореме Ферма** произв. в этой точке равна $0$.

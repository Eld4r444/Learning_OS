# Инструкции для LLM-агента

## Границы папок

- `raw/` — только чтение. Не менять, не переименовывать, не удалять.
- `wiki/` — можно править только на основе источников; у существенных утверждений должна быть ссылка на источник. Нет источника — `Source needed`.
- `learning/`, `labs/`, `projects/` — работа студента. Предлагай черновики, вопросы, ревью; не переписывай без явной просьбы.
- `_system/` — не менять без просьбы.

## Порядок работы с wiki

1. Прочитай `wiki/index.md` и найди существующую заметку по теме; дубликаты не создавай.
2. Одна заметка — одна идея. Добавь `## Sources` и `## Related` со ссылками `[[...]]`.
3. Обнови `wiki/index.md`.
4. Отделяй факт, интерпретацию и вопрос. Всё, что не проверено человеком, — `status: needs-review`.

## Режимы

- **Tutor** — объясняй и задавай встречные вопросы.
- **Examiner** — проверяй знание, жди ответ до разбора.
- **Reviewer** — проверяй структуру, ссылки и источники, не делай работу вместо студента.
- **Compile** — оформляй подтверждённые фрагменты в wiki-заметки.

Перед коммитом проверь: нет секретов и закрытых материалов, индекс обновлён, ссылки живые.

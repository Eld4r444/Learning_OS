# Карточки источников

Здесь лежат только метаданные и краткая аннотация источника. Сам материал лежит в `learning/<предмет>/Files/`, а для внешних ресурсов указывается URL и дата доступа. Карточка создаётся по шаблону [source.md](../../x_meta/templates/source.md).

Карточка не означает, что все утверждения из источника верны. Она нужна, чтобы их можно было проверить. Имя файла — `<slug>.md`, где slug короткий и английский, например `history-ru-fragmentation-lecture`.

Каждая новая карточка добавляется в [журнал поступлений](../../x_meta/log/ingest.md).

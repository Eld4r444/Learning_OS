## Структура

| Ситуация | Куда |
| --- | --- |
| Пришёл PDF, слайды, скрин, ссылка | `raw/<предмет>/` (вложения из Obsidian падают в `raw/assets`) |
| Лекция | `learning/lectures/YYYY-MM-DD-тема.md` по шаблону `lecture` |
| Не понял / вопрос | чекбокс `- [ ]` в заметке; общий список — `wiki/open-questions.md` |
| Разобрал тему и могу объяснить без шпаргалки | `wiki/concepts/тема.md` по шаблону `concept` + строка в `wiki/index.md` |
| Описать источник (книга, статья, лекция препода) | `wiki/sources/` по шаблону `source` |
| Лабораторная | `labs/YYYY-term-lab-NN-slug/` |
| Проект | `projects/YYYY-slug/` |
| Попросить ИИ проверить себя | промпт из `_system/prompts/` |

## Ритм

- **После пары:** файл в `raw/`, конспект в `learning/lectures/`, вопросы чекбоксами.
- **Раз в неделю:** 1–3 темы переносишь в `wiki/concepts/` своими словами, добавляешь в `wiki/index.md`, отвечаешь на открытые вопросы.
- **Перед сдачей:** оформляешь работу в `labs/`/`projects/`; если препод требует, указываешь использование ИИ.

## Правила

1. В `raw/` содержимое файлов не правим. Исправление — новым файлом рядом.
2. В `wiki/` только то, что понял сам, и у каждой заметки есть `## Sources`. Нет источника — пиши `Source needed` и ставь `status: needs-review`.
3. ИИ объясняет, спрашивает и проверяет, но не пишет за тебя. Подробнее: `_system/AI_POLICY.md`, `_system/AGENTS.md`.
4. Не клади в репозиторий пароли, ключи, чужие персональные данные и закрытые материалы курса.

## Frontmatter (минимум)

```yaml
---
type: concept   # source | concept | lecture | lab
status: draft   # draft | needs-review | verified
sources: []

---
```

## Obsidian

Открой эту папку как vault. Папка `_system/` скрыта CSS-сниппетом `.obsidian/snippets/hide-system.css` (включается автоматически; проверить: Settings → Appearance → CSS snippets). Шаблоны подключены из `_system/templates`.
